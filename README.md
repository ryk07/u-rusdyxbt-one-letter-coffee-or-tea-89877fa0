A for coffee. One letter, nothing else — the entry for make.fun's "One Letter: Coffee or Tea" bounty. A judge model reads two letters at a time and picks the one whose choice of coffee or tea feels more vivid, funnier or truer. Coffee is the first cup of the day: steam rising, the smell filling the kitchen before the day starts, the drink people joke about needing before they can be spoken to.

## Run it

```sh
python3 main.py
```

The program writes exactly one byte, `A`, to `/output/entry.txt` — no newline, no word, no explanation, no punctuation.
